# LFO Wiki Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Fumadocs-based wiki site for LFO (Legend of Fantasy Online) game content, with dark immersive theme, Giscus comments, and "Edit on GitHub" links.

**Architecture:** Fumadocs (Next.js + MDX + Tailwind CSS v4) provides the docs framework. Content lives as MDX files under `content/docs/` organized by section. Custom warm-amber dark theme replaces the default. Giscus component added to every doc page for comments. A landing page at `/` introduces the wiki before entering docs at `/docs`.

**Tech Stack:** Next.js 15, Fumadocs (fumadocs-ui, fumadocs-mdx, fumadocs-core), Tailwind CSS v4, MDX, Giscus, TypeScript, Bun (package manager & runtime), Biome (linter/formatter), Commitlint (commit message linting), Lefthook (git hooks)
