---
title: 角色資料說明
description: 系統說明 - 角色資料說明
---

當玩家登入帳號，選擇伺服器後，就會來到角色選擇畫面，這畫面將會顯示帳號內所有角色的資料。

1.這里會顯示玩家為角色更改的名字和此角色開創的日子時間。

2.顯示這角色的能力值。(不包含已穿裝備) 所顯示的能力包括以下數六項： 生命值、元力值、力氣值、攻擊力、防守力、敏捷度 。

3.顯示此角色所得的經驗值(EXP)﹑金錢(MONEY)和名聲(HONOR)。

4.顯示此角色的等級和使用人物圖像。

5.刪除角色的按鈕，按下後系統會便詢問是否需要刪除角色，如確定按 是 ，取消按 否 。

(小提示：請注意角色一旦刪除將無法復原，請慎重考慮後再做決定啊！)
