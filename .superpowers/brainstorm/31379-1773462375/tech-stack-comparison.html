Tech Stack: Which approach fits LFO資料博物館?

Static archive site • Dark immersive theme • ~48 characters, 19 sections • Traditional Chinese

A

Astro.js (Recommended)

Purpose-built for content-heavy static sites.

  • Zero JavaScript by default — ships pure HTML/CSS
  • Content Collections for organizing characters, stories, items
  • Markdown/MDX for content — easy to write and maintain
  • Islands architecture — add interactivity only where needed
  • Tiny output bundle — fast on any hosting
  • Built-in image optimization
  • Deploy anywhere: Vercel, Netlify, GitHub Pages, Cloudflare

Pros

  • Smallest possible output size
  • Perfect for static content sites
  • Content collections = structured data without DB
  • Great DX with hot reload

Cons

  • Smaller ecosystem than Next.js
  • Less familiar if you know React well
B

Next.js (Static Export)

Full React framework with static export mode.

  • React component model — familiar if you know React
  • output: 'export' for fully static HTML
  • Rich ecosystem of React component libraries
  • Image optimization with next/image
  • File-based routing
  • Deploy anywhere as static files

Pros

  • Huge ecosystem & community
  • Easy to add interactivity later
  • React skills transfer

Cons

  • Ships more JS than needed for static content
  • Heavier build output
  • Overkill for a static archive
  • React hydration overhead even for static pages
C

Astro.js + React Islands

Best of both worlds — Astro for structure, React for interactive bits.

  • Astro handles routing, content, and static pages
  • Drop in React components only for interactive features (search, filters, gallery lightbox)
  • Content stays as Markdown — easy to manage
  • Minimal JS shipped — only hydrates interactive islands
  • Can use any React UI library where needed

Pros

  • Lean output with surgical interactivity
  • Use React skills where they matter
  • Content collections for structured data
  • Best performance profile

Cons

  • Two mental models (Astro + React)
  • Slightly more setup

My Recommendation: Option C

Astro + React Islands gives you the leanest possible static output (solving your GitHub file size concern) while still allowing interactive features like character search/filter, image galleries, and smooth page transitions that will make the immersive dark theme feel alive. Content lives in Markdown files — structured, portable, and tiny compared to the current 540KB HTML blobs.
