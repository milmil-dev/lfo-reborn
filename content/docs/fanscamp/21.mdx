# 蕃薯集中營21

蕃薯集中營21 - LFO資料博物館 

### 

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營21 LFO官網移植計劃 之 蕃薯集中營 [2004-03-30] 蕃薯集中營 二十一 蕃薯集中營再次和大家見面，這段時間，還是為Close Beta來趕工。插畫組的大鼠、瑪雅和西瓜宗每日不停的在畫遊戲內的RPG插畫。由主角， 配角至嘍囉，全部插畫多達百多張。故事組剛剛將主角們的初段故事修改好，我們看過後都感到非常新鮮，希望大家玩過後會有一點點的驚喜吧。 至於音樂組，則因為看過故事後，之前作完的一些故事配樂，可能因此想作出修改，所以也在趕工。最吃力還是程式組吧！傑少和大莊主要忙於製作 RPG動畫，星爺和始祖則不斷編寫和測試程式。小熊則要將最初兩版的地圖設定好。Close Beta 會公開的兩版，是宣傳版內的學校和另一版「體育館」。 而學校的地圖比宣傳版內的更加擴大了。我們會在稍後的報告中，公開招聘Close Beta 測試員。第一期測試員會有100人，詳情請讀報告。 現在開始回答問題： 『danny009』建議增加天氣變化另希望原本就有武器的角色能夠卸下武器徒手作戰。答：天氣變化系統暫時未有，至於武器方面，對，所有角色一開始都 沒有武器，要自己去找。 『靈井』建議增加一些特別的關卡，需要組隊和一定人數才能闖關，當中有解謎的成份，但這些關卡一星期只開放一小時，每星期也不同，完成闖關 可有珍貴道具，但只能用一個月。答：這些都是不錯的建議，我想我們將來會設法做的。 『紙巾』強烈建議做外掛防禦！又問日後的LFO香港人真的會和台灣人分開不同的世界玩嗎？答：所謂道高一尺，魔高一丈。要完全防禦外掛會有一定的難 度，但是將來所有GM都會努力的。不過話時話，要在LFO有好的成績，玩家須要的是講求個人操控角色的技術，而非只是一般的打怪升LV和找寶物，所 以用外掛對玩家來講，未必太有幫助。至於將來是否香港人會和台灣人分開不同的世界玩？這個當然不會啊！Close Beta會在台灣有另一台伺服器的 主要原因，是因為我們希望台灣地區的朋友也能享受到高速的遊戲質素。 「無名fighter」建議1.希望LF前版的主角們外表在LFO內可以用隱藏人物的方式出現，讓高等級玩家使用。2.LFO可以在便利店內售賣遊戲，提高名聲。 3.定期在遊戲展、書展和嘉年華等場合舉辦格鬥大賽，借此宣傳遊戲。4.LF前版的所有人物是否都會在LFO中出現？答：1.這個暫時未有打算，因為工作 量太大。2.LFO絕對會在各大便利店發售。3.我們會繼續參加所有的大形展覽。4.所有前版的人物都會在LFO內出現，不過形式是什麼則有待大家發現。 『GaoFaiGar』建議加入一個「客務中心」頻道,GM可以隨時將一些玩家在遊戲內的問題即時解決，方便玩家，也可令玩家與GM之間多點交流。答：這是一 個非常好的建議，我們會認真考慮。 『Sword』建議有道具製作系統，角色可在遊戲戰鬥時拾到製作道具的材料，之後把它們拿到道具中，付上一定的金錢，把它們合成自己想要的形狀 和顏色，而道具上還會刻上自己的名字，戰鬥中這些道具不會掉下。答：已經有角色懂得製作道具，不過你所仔細描述的道具製作系統，因為太像 某遊戲，我們應該不會考慮。 『超級冰火佬』建議1.走路或跑步時會垂直上下微動。2.防止別人更改紀錄。3.例如：衝拳扣50hp改為扣50-55hp。4.將留言字數上限改為500。答： 1.會考慮。2.我們已經盡力做好這點。3.隨機的扣血系統是會有的，所以不是每種攻擊每次都扣減固定的體能。4.這個建議暫時未會採用，因為 之後官網會有大改革。請大家留意。 『邪火』建議在某些地方設一點陷入去的地方，給玩家們休息一會。過了某時間怪物就會來打你。答：很有趣的建議，可以試試。 『K-Zero』建議每個角色出場和結尾加進動作或口頭禪。答：現在某些角色會有口頭禪，但不會每個人都有，如邪鬼常常說某一句說話，那麼他看上 去好像變得不太利害吧？ 『neogeo』建議1.可以加一些有特別效果的道具，例如暫時加強功擊力，防禦力或速度等等。2.可以加入同伴功能，讓另一位電腦角色加入幫忙 你和你一起升lv。3.在遊戲中可加入交易所，讓別人進行買賣功能。1.會有特別效果的道具。2.同伴系統初時未有，將來應該會加設。3.遊戲內的大街 便是用作此原因。 『伊武深司』希望增加一些勝利和挑釁動作，增加趣味感。答：暫時不是每個角色都有挑釁動作。 『tzski』建議珍貴寶物要在限定時間內打敗頭目才可以得到。答：我們會考慮這個提議。 『andyblack77』建議增加一處為『LFO番薯學院』的隱藏地帶，裡面有LFO的製作小組成員，可以跟每位工作人員交談，供線上客戶服務、蕃薯文章 、心酸血淚史....之類的。答：這個和『GaoFaiGar』之前的建議有點相似，對我們都很有幫助，我們會認真考慮的。 |
