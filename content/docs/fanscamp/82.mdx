# 蕃薯集中營82

蕃薯集中營82 - LFO資料博物館

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營82 LFO官網移植計劃 之 蕃薯集中營 [2011-01-25] 蕃薯集中營 八十二 蕃薯俠：哈哈哈哈！各位元鬥士新年快樂！又到我蕃薯俠出場的時候了！！ 打雜工人：出現得真準時，可惜我還沒結婚，沒壓歲錢可給你。 蕃薯俠：不是啦！（倒）先問大家一個問題吧，「年獸」大家可能聽得多了，但大家有聽說過「凶獸」嗎？ 打雜工人：「凶獸？！」就是那只會在限定時間內出現的七凶獸嗎？ 蕃薯俠：對對對！這次本大俠出場是為了跟各位介紹即將於新年開幕的「凶獸樂園」！ 打雜工人：又「凶」又「樂」你到底想說什麼啊（汗“） 蕃薯俠：這個樂園將是有史以來首次將全部凶獸集合在一起的盛大展出，絕對是人類史上最偉大的魔物展覽！ 打雜工人：偉大是偉大，但如果不小心讓牠們都跑出來的話就．．． 渾身被火焰包裹的克拉雷、佈滿危險劇毒的杜巴、具有強烈腐蝕唾液的狂旺獸、 讓人一步一驚心的狄加以及超級射擊系的格諾斯等等．．． 各凶獸的實力均以紀何級數提升，其驚險程度保證令你眼界大開。一不小心，隨時火、雷、毒、石化等等異常狀態同時集於一身！ 蕃薯俠：樂園除了能給大家帶來驚險刺激的凶獸大戰外，更隨機跌出的新年套裝一經齊集，更會發揮意想不到的戰鬥能力！趁樂園開張期間，各位元鬥士記得好好去遊歷遊歷！ 當玩家完成故事後，便會有七凶獸同時出現！！！ 但請放心，可以不用打的〔笑〕，玩家離開這格地圖看便會有一堆野豬群可供玩家提升等級，經驗值絕對豐富！！ 千萬小心，如果繼續離開樂園的話就會完結任務了的喔。 另外，年近歲晚，ＧＭ們更會於「死亡塔大掃除！」一活動中跟各位元鬥士一起挑戰死亡塔。未曾擊破死亡塔的玩家便要趁這次難能可貴的機會和GM一起聯手「打掃」吧！ 前往活動網頁： !!請點我!! 蕃薯信箱時間又到了，請各位蕃薯們踴躍發問！ 無名氏問：泰加及安德魯什麼時候會推出異轉？ 答：安德魯相信異轉也差不多了，但暫時未曾收到泰加異轉的消息。 woody4891問：何時會推出最新章的故事？ 答：新章故事還在準備中，可以提示一下主線是圍繞星奇的。 天下無雙問：卡倫定人皇勁D？ 答：留待故事說明囉，說出來就不有趣了〔笑〕。 如果大家有問題想直接由蕃薯俠解答的話，可以將問題電郵到cs@littlefighteronline.com，註明是【蕃薯俠信箱】，每當蕃薯集中營刊出時，本蕃薯俠便會親自抽選來解答啊！ |
