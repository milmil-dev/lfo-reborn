# 蕃薯集中營16

蕃薯集中營16 - LFO資料博物館 

### 

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營16 LFO官網移植計劃 之 蕃薯集中營 [2004-01-27] 蕃薯集中營 十六 大家好，剛剛放完農曆新年假期，回來後第一時間便著手編寫蕃薯了。相信還有很多朋友在放假吧？怎樣？大家都收到不少利是錢吧？ 我在年假期間買了一些玩具，其中有龍珠和高達膠公仔。告訴大家，製作組內大部份成員都有收藏膠公仔的習慣。大鼠最愛IQ博士公仔，小熊 則喜歡星矢和龍珠，傑少喜歡狐忍和三國無雙玩具，而我便喜歡高達和超人系列。不過近來的玩具相當貴，而且有點不值。好像龍珠膠公仔便 一連出了數套，而每套也有什麼別注色，抽到全個都是銀色的公仔真的不知怎樣處理。又不喜歡它，但掉了又感可惜。 《LFO人物創作大賽》已經在上星期截止參加，最後一份收到的作品為台灣sam0429寄來的「鬼斧山姆」。現時大鼠正忙於處理所有收集到的作品， 將它們數描好，再加以整理，才能將它們放在官網內，然後開始公開投票。相信今次的比賽都會很激烈，因為有水準、創意加畫功的作品很多， 而最高興的，是女玩家所寄來的作品也有數十封，證明 LFO 確實也能吸引到女性的。 由於上星期放了年假，所以工作進度也是和之前差不多，最高興的應該是終於在官網內推出了《LFO宣傳版2.0》吧，你們都玩過了沒有？不過始 祖發現由於太趕，希望在年假前推出，所以不小心將馬龍的能力數據，變成了跟米兒的一樣。將來上市正式版內的馬龍，HP和防禦藉會比較多。 好吧，是時候回答問題： andyblack77 建議可以加一些破壞環境的效果。答：應該會有這種效果。 neo_w43 說《LFO宣傳版2.0》的人工智能偏向防守，行動模式千篇一律。玩家攻擊，電腦便進入防禦狀態，確實是令玩家不爽的人工智能設定。 希望完成版不會有以上問題。答：其實我們將會設計數種不同的人工智能，然後根據情況，電腦會選擇那一種比較合適。宣傳版只夠時間完成一種。 fighter1204 有可以讓所有玩家聚在一起的地圖嗎？答：有，這便是我們即在動工的那條大街道。 ianlau 有沒有方法可以解決時常彈出遊戲的問題。答：我們會將 LFO 的基本電腦硬件需求例出，通常排出遊戲的問點是基於電腦的記憶體不另足。 超級冰火佬 問工作人員會否看所有留言？有否看到關於他減SP的建議？又問可否做LFO的管理員？答：第一，已經看過你的留言和建議。SP的建議不錯， 其實宣傳版內SP暫時未有多大作用，我們會將它對遊戲的影響調整一下，在正式版時相信你們會名顯見到它對角色的影響。第二，現時未有為留言區找 管理員，不過LFO正式上市後，官網確實需要找人幫手。我們也樂意找LFO之友幫手，但首要條件是為人公正，說話不會攻擊別人，亦樂於幫助新手。 hocti問現代武器就火箭炮、榴彈炮、地雷、手榴彈、槍、電槍、電鋸等武器會加入遊戲內嗎？答：LFO正式第一版的內容已經定好，應該未會有這些武器， 但之後的第二或三版則會視乎情況而看可否加入這些武器。 腦細胞 問在LF2裡，往前跳躍後再按往前跳，後面跳的那一段會變得比較長，而且按攻擊還可變飛踢，可是在《LFO宣傳版2.0》裡卻變得一樣 長度，而又沒辦法快速逃跑或連接飛踢，這是怎麼回事？答：其實每一個小功能都要時間放進去，我們會先選擇將最有用的功能放進遊戲內，然後才看時間， 慢慢將其他的動作都放進遊戲內。 |
