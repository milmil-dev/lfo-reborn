# 蕃薯集中營11

蕃薯集中營11 - LFO資料博物館 

### 

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營11 LFO官網移植計劃 之 蕃薯集中營 [2003-12-20] 蕃薯集中營 十一 很快又過了一個星期，又要做蕃薯集中營了，終於知道外面從事編輯的人，做一本定期刊物也不是容易的工作。這個星期，連今天晚上計算在內 ，已經是第三天的做通宵了！我們要趕好下星期三在【亞洲遊戲展 2003】中所須要的東西，也在此介紹一下吧： 插畫師「大鼠」做了一個五呎高、十呎長的「邪鬼」放在越一科技《小朋友齊打交 Online》的攤棚頂！利害吧！門口兩邊亦會放兩個真人一 比一 size 高大的 Davis 和 Stinky！而我們亦會設置四部連線電腦，全部安裝了最新的 LFO 網絡測試版 ver 2.0，讓到場的朋友一試組隊作 戰或對戰的好玩處。小熊說會再次藉這個機會，在會場賣 LF2 Davis 公仔。今次他會小心身體，務必在會場出現，而始祖、星爺、傑少和大鼠 也會輪流在攤位中出現，希望到時會見到大家，和所有支持本遊戲的朋友交流一下創作遊戲的心得。不過製作人員到達會場的時間表，則要到下 星期初才能在官網內公報，因為製作組所有人現正在埋頭工作當中，等我們完成後，立刻會編排到場的時間表。再提一提，我們的攤位在大會近 左手邊入口處，所以當你從左邊入口進入時，應該可以立刻見到一個巨大的邪鬼，雙手舉向天的怒視著你！ 過去兩天我們還要趕及完成 《LFO 中文宣傳版》，現在已經完成了！不過我們現時還未可以將它放在官網內，讓各位 LFO 之友下載。原因是這 一個 LFO 版本，雖喚作宣傳版，但它的內容便已經非常豐富了。全個檔的大小差不多 150 MB，比 LF2 大十倍，以一般寬頻的速度，下載也須要 半小時，不過這也不是最大的問題。我們真正要面對的困難，便是網絡擠塞的問題了。試想想，以 LFO 支持者的人數，同一時間可能會有好幾百 人在下載宣傳版，製作組預算必定會引致網絡擠塞，如果將《LFO 中文宣傳版》放在官網內，很大機會連官網也會被拖垮！現在官網的伺服器的 設備只是預計使用者瀏覽網頁和下載圖片之用，所以未能應付多人下載的工作。我們已經在積極尋找方法，亦聯絡了一些大型的網絡供應商，應該 會很快解決這問題，然後在官網內公開《LFO 中文宣傳版》，讓人下載。 不過大家也不用失望，製作組知道大家都非常期待 LFO，所以我們已經將《LFO 中文宣傳版》印製成 CD，然後在【亞洲遊戲展 2003】中免費派發給 LFO之友。可惜的是我們的錢，也只能夠印製數千隻 CD ，而聽說到【亞洲遊戲展 2003】的人數，會多達 20 萬人，相信會很快派完！所以想要 《LFO 中文宣傳版》CD 的朋友，一定要記緊早點到場啊！ 說到金錢問題，我們的錢，很多都已經用作開發 LFO 了。剛剛和始祖、星爺、小熊吃過晚飯，回來再開工了。為了省點錢，我們都只是隨便吃點東西， 小熊吃了一碗十元的豬紅粥，始祖則吃了墨魚丸米線，星爺吃了雲吞麵，而我便吃了車仔麵，有魚丸和蘿蔔。聖誕節將近，街上都很有節日氣氛，我們 看到有很多人一家大小的出外看燈飾，很是熱鬧。當回到我們工作室的商業大驉A冷清清的，什麼人也沒有，令我們也有點意志消沉。不過我們都相信 努力做好 LFO，是不會白廢心機的。這個遊戲，經過十個月的努力，終於將近完成了，非常感觸，真心希望這遊戲能成為大家喜愛的Game，至少，我們全組 33人已經盡了全力，這個遊戲的成與敗，明年初便有分曉，你會支持吧？ 今次不回答問題了，還有很多東西要做，下星期再答大家吧，再見！ |
