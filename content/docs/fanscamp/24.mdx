# 蕃薯集中營24

蕃薯集中營24 - LFO資料博物館 

### 

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營24 LFO官網移植計劃 之 蕃薯集中營 [2004-04-19] 蕃薯集中營 二十四 各位蕃薯您們好！不知不覺又過了一個星期，時間過得很快，我們製作組同時已經加快步伐，要趕及將LFO第一版完成，離推出市場的日子不會 太遠。當然在這之前，測試和改進的工作不會停止。Open Beta亦會在不久後推出。由於大家都忙於開發和將Close Beta內各測試員所面對的問 題續一解決，所以很難即時回應一些測試員電郵過來的問題，希望大家見諒。不過在現時的測試員中，最積極進行測試另回報我們的有幾位， 分別是強人皇、hocti、avatarofwarz、Leung Chi Hang、alanyam等。其實，為了答謝所有的測試員，我們會在閣下將來的LFO帳戶內，送出一 些特別的禮品道具給各測試員，以示我們的一點點心意。而我們亦會在Open Beta推出之前，在眾多測試員中，選出【十大傑出測試員】。被選 中的測試員，美術組已經精心設計了一個非常特別的角色，將來特別給予你們尊利使用！ 本星期趕做Close Beta 3.01，其實上星期「始祖」已經推出過一個更新檔，不過由於所更新的不太多，所以沒有公報，至於3.01內，最突出更 新了的，莫過於『連招指示器』了！假如閣下使出連招擊中敵人，連招指示器便會在對方的頭頂出現，而我們暫時最利害試過9連招，不知各位 測試員又能否突破此數字了？Close Beta 3.01會於今天推出，各測試員留意了！ 而第二階段的測試員，我們亦會在另一通告中公報測試員名單，因為看見想做測試員的人數上升得非常非常之快，（現今總報名人數為4722人）， 我們決定將第二階段的測試員人數增加。所以今次我們會選出150位測試員，請所有報了名的【LFO之友】留意了！ 最後談談【LFO人物創作大賽公開投票】吧！我們推出已經有一段日子了，而製作組亦認為應該是時候完結投票時間，所以我們決定將投票設定於 4月23日（即本週末）完結，而我們亦看見冠亞軍作品真的爭戰得非常激烈，究竟冠軍花落誰家？本星期自有分曉。 現在回答問題： 『josephchen』 希望能夠把人物的眼神改得有個人獨特的風格。答：我們也知道現時遊戲內的角色沒有多大的表情，已經將之向美術總監提出過， 應該會有一些更改的。 『無名fighter』建議當戰局主人忘記開始時，螢幕上的開始鍵會閃爍一會，以便提醒戰局主人，過一會還沒開始會再次閃爍，再過十秒後，戰局 主人就會自動退出戰局，讓第二位玩家主持戰局。答：我們也想過類似的情況，不過如閣下提出的，在技術上推行有點困難。 『小哲』建議設計些有影的招式像使出百烈拳時，那些影也有攻擊性，只不過比實體的力量差很多。答：影子的攻擊？不錯的提議，可能會為石谷 忍設計一些用影攻擊的必殺技吧！ 『picturemei123456』問 LFO 出漫畫好不好？答：好！當然好！ 『super_fenixGOD』建議遊戲可用操控竿來進行。答：可以考慮。 『Aberdeen Chan』建議：加設新手訓練營，先讓新手試一下對話、對戰和交易．．．等等系統。答：遊戲大街有此功能。 『張元明』建議能使人物合體，例如特定人物能合體，然後一段時間內攻擊力、防禦力和絕招都變強。 一段時間後回複平常狀態，但血會變少。 而融合失敗也有可能使角色力量數藉下降。答：會有合體技，而回複平常狀態或融合失敗後，角色的血會減少，這是個不錯的提議。 『neo_w43』建議：每一次角色復活，都會損失少量經驗值和金錢，而身上的其中一件道具則會遺留在戰死的位置。答：現在Close Beta中暫時未做， 但是這個功能一定會有，否則遊戲會變得沒意思。 『KobeIp』建議制作2個或以上角色一齊打出的絕招。答：其實我們很早之前以經說過會有「合成技」的，相信這和以前的版本是很大的分別。 『kkrc』建議防止玩家於某能力藉中瘋狂提升，還要防止老手屈死新手。答：我們不會阻止玩家選擇升那一個能力藉，至於防止老手欺侮新手的方法 ，之前有提過。 『Sword』LFO正式版推出時，角色的招式會否與宣傳短片中的一樣？例如迪雲的昇龍霸中，會否出現一條龍？答：將來當然會跟宣傳短片中的一樣。 迪雲有龍的昇龍霸是高等級的昇龍霸，好像叫『終極真昇龍』。 『項天仇』建議角色升級後，會提供一定點數給玩家分配至每一種能力，能力應該以lv計。升lv所需點數一級比一級多，而能力升lv所提升的數值 會越來越少直至到達某lv突破瓶頸為止，之後能力會暴升。答：完全是我們設計的升級策略，現時升級系統未做好的，只是隨意做些點數來給玩家加， 我想之後會有更改。 『blaze』希望 LFO 能加重 RPG 遊戲的味道，例如可以在一些區域探取一些情報及領取任務，才到其他地方闖關，現在只有大街實在不夠。答：將 來大街亦不是用作此用途，不過你所提議的會有，但會是平均分配在遊戲的版圖內。 『fighter1204』請問最高等級可以到幾等？答：Close Beta暫時未有設定。 『alanyam』建議1:死者遺物要在10秒內，兇手不拿走，其他人才可拿。建議2:定期舉行淘汰賽，第一場勝出者可有獲得某數字的獎金，第二場 勝出者也可獲得某數字的獎金，如此類推，冠軍者便可獲豐富獎金，而落敗者亦不必有何損失。建議3:擋的時候需要sp。建議4:升lv或打字時， 可暫停，但不可太久，以免濫用。建議5:人物需要攻守兩備，不可像Stinky一樣，全是近攻。不過近攻的角色近攻招數應比遠攻多，而相反遠攻 角色亦是同樣，但不應連一招近攻或遠攻也沒有。答：1.角色被打敗後，某一道具在他的身上會跌出來，其它任何人，包括npc都可以拿它。2. 會有淘汰賽，但勝利後或被打敗後的獎罰跟你所講的有不同。3.擋是會需要SP的，所以當角色沒有SP，而對手向他攻擊，他是不能防守到的，必定 要避開。4.會有暫停鍵。5.每個角色都會有遠和返的攻擊。至於星仔，他是個利害的角色，但他最利害的絕招，全部會在較高lv時才出現。就正如 他在故事內一樣，因為他是個新手嘛！ 『ZeroExe4』建議加設朋友系統，可以召喚npc來幫手打人，不過可能召喚不到，這是看玩家有多少運氣值。答：不錯的提議，其實我們已經設計了 會有npc幫手的系統，正如LF前版一樣，會有npc幫手的。 『Ianwind』建議可以用時光機的功能，帶玩家到過去，如：古希臘羅馬、新時期時代跑出恐龍或未來兩億年後的巨龜，讓高手去挑戰。答：奇怪的 對手，隱藏版圖等都會在遊戲內出現。 『堯堯』建議加入潛力值，每當發出一次攻擊後，潛力值就會增加。當儲滿一定程度，便可發出強力一擊！數值就會重新開始儲值。答：非常好的提議！ 我們會慎重考慮的。其實很想做，看時間而定吧！ 『chanwanfat』應該有「回點丸」，即當有一些點數加錯了，可用遊戲內的金錢買「回點丸」，再重新把所有升級得來的點數從新再調整一次。 答：應該不會有些道具，因為我們都希望玩家可以慎重的思考自己怎樣培育角色。 『~~~馬騮戰士~~~』建議當人物Lv較高、金錢足夠的時候，可以到商店街買一個店鋪。也可以自己建造一樣建築物如：醫療所、習武館等。可以選擇私人 (即只讓建造者或得主人許可才能先進入)或公開(其他人須付錢才能使用該設施)。答：您所提出的建議，其實跟我們所設計的公會系統有點相似。 『強人皇』問製作組是否每個伺服器內的大街樣貌都會一樣？ 答：暫時的設計是一樣的。 |
