# 蕃薯集中營17

蕃薯集中營17 - LFO資料博物館 

### 

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營17 LFO官網移植計劃 之 蕃薯集中營 [2004-02-16] 蕃薯集中營 十七 大家好，已有一段時間沒製作蕃薯了。製作組近來都忙著要完成整個遊戲，盡快將 LFO 推出市場。我們一方面要做遊戲的開發，而同時我們亦正 準備作很多上市的宣傳活動。其次便是安排其他地區的上市工作，當中首要著手的地區，便是台灣和中國大陸。 先談談開發進度吧！這段時間，主要針對連線工能的更新，我們的伺服器經過一輪測試，要應付多人同時加入遊戲，相信沒有大問題。我們會在 香港設立第一組服務器台，相信離推出 close Beta 的日子不遠了。而將來台灣地區亦會設有獨立的一組伺服器，安放在台灣，所以台灣地區的 LFO 之友連線玩 LFO 時絕對不會慢。相信這期蕃薯推出時，老總正在坐機往台灣，商量 LFO 在當地推出時的工作。 另外遊戲內容方面，我們已經將所有遊戲的基本進行模式做好，當中包括：單機模式，故事模式，對戰模式和淘汰賽模式。而用來給 LFO 之友 作交談的大街也完成了七七八八。至於遊戲角色選人介面，伺服器選擇介面初部也完成了。現在全組程式組和插畫組正開始大量製作遊戲故事、 任務、RPG遊戲動畫、RPG人物對話圖和遊戲完結畫面。現在初步完成了五位主角的故事，而其他角色會在本週進行。人物對話圖有幾百幅之多， 大鼠也畫至筋疲力盡。 我這幾個星期正忙著動手製作【LFO人物創作大賽】的公開投票。因為參賽作品有數百份之多，而我們只會將較好的百多個作品，放在官網上讓 大家投票。而當中所有作品都是實物，我們已經將最好的百多份作品選出，而現在正為每一份作電腦數描，再將它們處理好，才能在官網內公開， 讓大家投票。要從幾百份作品中選出百多份也不是易事，因為很多作品的創意也非常之高，不過因為比賽的關系，我們亦只能讓較好的出線。當 我們將進級的作品處理好，會很快公開投票，請各位耐心等候。 現在回答問題： hocti 建議:回復lf2精細設定，如70爆擋值、70肚痛值。2.肚痛和暈是不同的，希望回復肚痛。3.一般動作的攻擊速度，攻擊距離和時間也有別。 如 Davis 跳攻很慢才出到和 Louis 出拳慢。答：其實很多以往有的工能，在新版中亦希望加入，如hocti所提出的，但畢竟以往lf2是用了很長 的時間慢慢更新和修改，所以LFO在最初期會有一些工能暫時未有，會在更新版內推出。 霸風建議︰可以自創招式（組合招式），和替自創招式命名，當然只能創一至二招，和有些限制才能自創招式。例：等級到達５０。答：自創招 式的想法非常好，但要實行出來會有一定的困難。 rlf3 建議在戰鬥時設定角色狀態圖。如果玩家操縱角色好的話，攻擊力、速度會短暫上升；相反玩家操縱角色不好的話，例如HP低時，角色會 露出不安的樣子，會降低速度等。答：建設很抽像，什麼是操作得好？什麼是不好？而且這樣的設定，會否讓越利害的玩家變得更利害，而比較 弱的玩家如新手便更弱了。這樣會引起遊戲不平衡吧。 zxswcvfrbnhy 建議打敗敵人後會得到金錢，可以買到武器，最重要是可以儲存。答：一早已有這種計劃。 ㄨ疾風ㄨ 問台灣區的玩家玩會不會LAG機？光碟大概哪時候可以買到？ 答：台灣區會有伺服器，所以遊戲速度會很快，不用擔心。而本年春天， LFO 會在香港，台灣和澳門同時上市，敬請留意。 GaoFaiGar建議「以一敵十拳」：其實只是普通攻擊，不過現在的普通攻擊不可以一拳打多個人而是一拳只打一個人。當一堆敵人圍住的時候， 便不可用普通攻擊把所有敵人攻擊而要出魔法或想辦法了。答：一拳打多個人這樣利害的招式變成普通攻擊？這種角色未免大過利害吧！還是將 它變作必殺技使用吧。 |
