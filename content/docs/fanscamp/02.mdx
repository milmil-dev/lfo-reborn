# 蕃薯集中營02

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營02 LFO官網移植計劃 之 蕃薯集中營 [2003-10-06] 蕃薯集中營 二 安安大家好！很快又過了一個星期，蕃薯集中營再次和大家見面 (^_^) 上星期可能因為有假期，所以官網多了很多朋友參加，而留言區也變得 份外熱鬧！最新今期香港遊戲雜誌 GamePlayersOnline 遊網誌和 PC Game 2000 也再次有 LFO 的報導，有與趣的可以買一本來看看。居住台灣 的朋友亦不用擔心未能收看本遊戲的第一手消息，因為越一科技有限公司亦已經和台灣某遊戲雜誌聯絡過，相信在不久的將來，台灣區的玩家亦 可以從雜誌上看到 LFO 的資料！也不妨在此問問台灣的朋友，請問您們最愛閱讀哪一本台灣遊戲雜誌呢？希望熱心的 LFO 之友可以在留言區內 告訴我們。 其實我們每天一直有看留言區內的留言，不過總不能立刻回覆吧，這樣會嚴重影響 LFO 的開發進度啊！所以希望大家留言後不用心急，我們會 收集所有問題，然後在這裡盡量回答大家的問題，好不好？ ^o^ 現在開始回答問題： 有朋友不明白蕃薯集中營這個名字的意思，其實蕃薯即是地瓜，不過在這裡我們是用它的發音，說起來很像英語的 FANS，所以蕃薯集中營的意 思就是一個地方讓 LFO 的 FANS、支持者集中在一起的意思。 LFO 的人物原先設定為三頭身的Q版，很可惜大部份的玩家都不太認同。原先製作組是有特別的用意，希望給大家驚喜的，不過現在迫不得意 要提早將這小小秘密公開了。其實每一個角色在遊戲中是會不斷的成長，由一個小孩子開始，當角色本身能力和等級到達某個水平時，玩家的 人物不但功力和必殺技增加，外表也會變得成熟了。原理就好像打藍球一樣，未打過又怎會高呢？我們的原意是希望玩家能對自己喜愛的角色 投入多一些感情，看著自己一手培育的角色逐漸成長，滿足感會更大吧！更可況在故事中，如果主角們一開始已經是一等一的高手時，那麼故 事的趣味性亦會減少吧！不過 LFO 美術組見大家也想要成熟一點的做型，我們決定不怕辛苦，重新將所有人物比例更改，真的是非常非常艱巨 的工作，希望大家會支持我們吧！ Ricky Mok 問 LFO 將大約有多少位女角? 答案是第一版將會有四位。 jollyckc 您自己設計的人物不錯，不妨告訴您，其實在 LFO 內已經有一位相當厲害的角色做型和你那個有點相似，將來多加留意吧！相信會 帶給你驚喜的，希望你也會參加LFO人物創作大賽。不過提一提，其實你不用將作品在留言區內發表多次，因為從您第一次發表，我們已經將你 的作品收藏好了，而且這樣會被人誤會為洗版呢！ hocti，看過你的CG畫後，令製作組知道你心目中的John是怎樣的，謝謝！我們原意是希望令小約翰看上去 帶點智慧的，所以給了他一副眼鏡，萬萬料不到會令人誤會他是某電影人物，美術組已經立刻作出修改了。 基路亞建議在戰鬥場地中加入天災等工能，這個想法很特別，我們也認同可把遊戲的耐玩度及剌激性大大提升，製作組會想想在適當的時候加入 這種玩法。 ccc2 說非常期待雷系的角色，更希望有電彈類的招式加入。告訴你電彈就不會有了，不過用電來攻擊的絕技也是相當特別和利害呢！ neogeo 建議可以提升武器的經驗值，這會不會有點怪？理論上武器和裝備用久了，質量只會越來越變差，怎會反而變得更利害了？ 告訴你吧， 這次 LFO 內的角色，他們的必殺技全部都可以升級的。比如迪雲的「昇龍霸」，升級後會變成「昇龍殺」，最後更可進級成為「終極真昇龍」！ laimoping 發現了人物介紹中的henry中文打錯了，對是亨利，不是享利 :P 鬥士王希望能把角色們都改有最後爆發性的殺招：『如生命剩下一點時可以使出一次大絕招，但自己也會同歸於盡而死。』大絕招建議不錯，但同歸 於盡則可能不太好，因為會很容易令遊戲失了平衡。 項天仇你那個非常詳盡的建議已經看過了，真辛苦了你，謝謝！ 最後 deepking 問官方會不會採用「本週最佳留言」內的建議，答案是如果可行，我們是會仔細考慮的。 |
