# 蕃薯集中營31

蕃薯集中營31 - LFO資料博物館 

### 

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營31 LFO官網移植計劃 之 蕃薯集中營 [2004-07-05] 蕃薯集中營 三十一 各位親愛的蕃薯，三十一期集中營終於在千呼萬喚之下，又再次在衝衝忙忙中寫成。我知道大家都很焦急地想了解遊戲的開發進度，而小弟通常 都會在繁忙的工作中，每隔一段時間就會自然想起各大蕃薯，其實早在上週五我的心已經常常提醒自己是時候出蕃薯，可能我想連版頭的主圖一 起更新，所以要等西瓜宗完成最新的主角圖後才開始寫集中營。不過話說回來，我真的很欣賞新的主頁圖，漂亮很多啊！而且我覺得此圖更加顯出 各主角們的性格來。其實西瓜宗除了畫好這一張圖外，（聽老總說會將它印制成海報！）他也完成了另外三張更精彩的海報！原因是我們會在此幾 張圖中選出一張來作為上市時遊戲紙盒面圖。 至於遊戲內的開發進度，這兩個星期，主要工作是制作對戰模式。小熊已經為對戰模式加入了很多新工能，希望會藉此令它更吸引玩家們開戰。 始祖則繼續更改對話系統，而星爺則幫手開發道具系統。至於莊青，他已經為其他角色完成故事。現在十五位主要角色都有故事模式了，還餘下 其他數個有特別故事的角色需要完成。 上星期我們製作組接受了香港的雜誌「天馬行空」訪問，所有同事都被問過開發心得，其中又以西瓜宗發表了他的「偉大言論」令人最為感動！ 這篇訪問相信都不會短，相信會在七月中的那一期刊登，我們也將一些遊戲圖交給「天馬行空」的編輯，包括了未公開過的第四版冰火皇后島， 有興趣的朋友，到時可以買一本來看看。 最後老總說會在暑假期間舉行一次《LFO之友研討會》，這是因為之前承諾過一些蕃薯的，現時日子和地點還未定好，會再次在蕃薯集中營中報 導的，請大家留意。還有一點，還有一些台灣的測試員未曾作好整個登記程序，我們會在工作時段，繼續開放的，請大家以MSN通訊吧。好現在解答問題： 『何謙』認為遊戲內一定要有連續技，使打鬥場面更加激烈！和boss的能源一定要比其他角色高。答：測試版已經有很多不同的連技，至於頭目的 能力，嘿嘿，保證您會說「很難打啊！」 『kevinanguslau』建議:闖關時可能得到屬性卡(火、水、土、風)，加上招式上會有不同效果，如加火會?加攻擊力和有火焰效果，水會令招式 生效時間更長，令招式發出得更遠，土會令招式的命中率提高和攻擊範圍更大，風則令出招的時間更快，令招式更快打中敵人(巨龍波，散彈波…) 答：每成功闖過一關時，玩家都會得到一些這具以作獎勵，不過未必如你所說是屬性卡，至於你所講的屬性，多少對我們都有一些啟發，謝謝！ 『強滾』建議：新增一種類似「小朋友齊跑步」的模式，遊戲規則就是只要跑到終點即算過關，不過在當中可以任由玩家出招來阻撓對手且可增加 一些像地雷，毀損天降...陷阱增加刺激性。「小朋友齊跑步」模式：可分為兩種，一種是玩家有血，另一則是無血；有血的就是假若在跑步中 被玩家或陷阱打死的話，即over(此時可按方向鍵控制畫面)；無血的就是即是反之。答：您所提議的模式好像很刺激，小熊說可能有朝一天有時間 會將它製作成小遊戲，在遊戲內讓玩家玩。 『豪之狂怒』建議官方把LFO改成可以玩2 Play的狀態這樣會吸引比較多的玩家，不然線上玩家這麼少，我家沒2 Play得很無聊。答：相信不會 做單電腦有雙打的工能。 『alanyam』建議可以見到所有在線玩家和他們身處的地點(那間房或大街)，不要只見到盟友。答：始創新製作的通訊系統將大大提升現有的工能。 『梁偉』希望LFO有完善的升級制度(反對外掛等程式)，另外加入攻城就更加緊湊啦！答：已經有升級制度，而且還在更新中，至於攻城，將來會有的。 『apple545』官方人員都不在發表區回答！也沒辦法跟他們聯絡。製作人員，你們已經變得好了不起，我還有辦法繼續跟你交往嗎？答：我們沒有變得了 不起，只是因為要尊心趕制好遊戲，所以未能常常都發表區跟各位交談。我們很歡迎大家成為好友啊！因為大家都是LFO之友嘛！老總亦向我們說要放多 些時間跟蕃薯們交流，所以我們會盡量到發表區的。 『j20307』和『lkk910921』都覺得LFO人物的眼神都少了一種霸氣。妳們要考慮人物的眼神都有他們特點，不然看起來都呆呆的感覺。答：其實 美術組一早已經完成了很多不同的表情，只是程式組這邊未有時間放進遊戲內吧！ 『星卍碎片』想問星奇是否有3招超必？答：請到官網內的「角色介紹」內看。 『火龍皇帝』建議可買獅子，老虎等騎來咬人，隻獸有lv、hp、mp等。有馴獸度，馴獸度50以下會咬主人。答：這個建議很好，雖然我們還未有計劃做 寵物系統，不過你的建議，特別是馴獸度很藉得參考。 『v27855』希望LFO可以有大量精密武器，而且為何少林寺有地雷，什麼少林寺用科技？我有個好提議，便是將地板做一些洞，行到那處會跌落下層。答： 會有很多武器。因為霍雷寄住在寺院內，而他本人又愛發明，所以將那處改建。地上有洞也是一種陷阱，在後期的地圖中會出現。 『king of lf2』建議增加寶玉，要當玩家取得它才可以使出招式，就算學會那招式也不可以使出，要使用寶玉才可以出招。答：不錯的建議，小熊說會加進 任務模式中。 『魂鄭』每個人物都會有幾種需要，例如睡覺，有一定時間都可以休息。這樣不但遊戲人物可以休息，玩家都可以休息，一舉兩得！除了睡覺， 還有上廁所，玩遊戲，養魚等等！答：將來遊戲內會加入一些小遊戲的，相信會增加樂趣。 『hocti』也許LFO很努力在stage上，但stage和vs比，重要性只是3:7左右，甚至更少。與其努力做二等而大量的事物，倒不如把時間表調調位 ，先把重要的集中一次過做。順手加個建議：offline版也能save，不必每次由level 1開始，而且可以隨時停下來，還可以用IP連線和支援800*600。 可以的話，能加入自創人物和data。答：製作組是分工合作的，有些同時做每一版的內容同時有人會製作對戰模式。不過工作量其實很重。至於你的建議 ，相信offline版是一個較短的模式，所以不會有save工能。而IP連線工能應該不會有。最後自創人物這方面，我們也商議過，但暫時不會做。另外，老總 曾經吩咐我在蕃薯內向你說句謝謝，那很長的建議和報告，雖未能在此回應（大長），但我們都已經看過，也下載了。 『無名fighter』建議加入臉紅、害怕、勝利、大笑、打招呼表情。答：小特突已經馬上動工了！ 『克魯培羅斯』希望LFO能不只刊登在一本雜誌上，希望是多本雜誌，這樣會使更多人知道LFO，我最喜歡看的雜誌是e-play和e-plus。答：在適當的時候，我們 會作大量宣傳，所以不會只有一本雜誌刊登LFO的消息。e-play和e-plus嗎？好我們會好好記著的！而且上星期台灣的遊戲展也邀請我們到台北去 作展覽，我們也正在考慮中。 『Ianwind』建議在遊戲中，人物再最高等前三等時有些特殊的能力和限制，特殊的能力可以增加遊戲的傳說性。答：好，會考慮的。 |
