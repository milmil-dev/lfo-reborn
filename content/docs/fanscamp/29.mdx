# 蕃薯集中營29

蕃薯集中營29 - LFO資料博物館 

### 

| | 博物館大廳 ‎ &gt; ‎ 蕃薯集中營 ‎ &gt; ‎ 蕃薯集中營29 LFO官網移植計劃 之 蕃薯集中營 [2004-05-28] 蕃薯集中營 二十九 Hello！蕃薯俠來了！大家好嗎？本星期還是一樣，努力工作。我們現在已經開始制作第五版了。由於星仔跟迪雲的經歷會開始有很大的分別， 所以我們制作組便唯有兵分兩路，一時做星仔的故事，一時做迪雲的故事。整體來說，迪雲和星仔的故事，發展都是各有各精彩。喜歡玩冒險感 重的朋友，可能會比較喜歡迪雲和悟地的劇情。而喜歡劇情性和格鬥故事味重的玩家，可能會覺得星仔，小丹和米兒的故事會較吸引了。 始祖和星爺每天都為 LFO 的遊戲工能煩惱著，由於有太多不同的工能想加進去，但又來不全部於短時間內完成，所以便唯有定下工作的先後次序。 首先，他們會為VS MODE新增工能。由於我們發現大部份玩家其實都很喜歡玩對戰，因為可以證實自己的能力，但可能由於開設對戰房時，沒有其 它事做，但其它玩家又察覺不到有人開了VS房，所以久久未能進行遊戲。這個原因，令本來很好玩的對戰場變得冷清清。為了令更多人玩VS MODE， 我們將為VS MODE內增加特別遊戲，令玩家在等待之餘，也能繼續進行遊戲。始祖和星爺的一片苦心，希望真的能夠令本來冷冷清清的對戰場重現生 機啦！ 先科美術組剛剛將 LFO 的開場動畫影片完成，現已將它轉送到音樂創作組那邊，只要加入美妙的音樂和強勁的聲效，全套動畫便會完成。我自 己非常喜歡 LFO 以幽默風趣的拍攝手法來介紹各位主角。美術組下一步會全力制作其它版圖的新怪物和遊戲內的武器、防具等。 上星期天舉行了第一、二、三階級測試員的最後補領日。這天，很多蕃薯亦趁機來到公司，希望和我們見面，亦談談LFO的遊戲心得和建議。很可惜 由於我蕃薯俠那天有點事做，未能出現，錯過了跟其它蕃薯見面的好機會，真可惜。不過，前一天老總已經千叮萬囑小熊務必出席，所以小熊於翌日 便抽空出來和FANS會面。當然這難得的機會，我們亦更能了解和明白到遊戲方面的問題和大家的意見了。小熊很高興，另想答謝大家都沒有保留的，大 方地將意見和心得分享，那天他說自己獲益良多！ 莊青一連兩個星期跟台灣的測試員作登記，現在已經有70多位台灣測試員加入測試的大家庭了！希望各方好友繼續大力支持，將遇見的問題和建議郵寄 給我們，務要將LFO改善至最好！ 現在回答問題： 『小哲』建議在故事模式裡加些特別效果，像震動或建築動被破壞。答：小熊已經在第四版冰火皇后島加入此工能。 『atheist』建議1.當hits越高時，會有傷害加成。2.連段也可以加上評語，像是5 hits GOOD!!10 hits NICE!!25 hits BINGO!!之類的...答：1.可以考慮。 2.不錯的建議。 『andyblack77』建議1.有公會系統，且有一種遊戲模式叫「戰爭模式」，供兩組至四組公會互相廝殺。2.有LFO系列的商品。3.可以自己製作陷阱，如 地雷，將之埋藏在地下後，可以將「倒楣鬼」炸飛！！答：1.公會系統遲些會開始做。2.會有LFO系列的商品推出。3.自己製作陷阱的工能會有，不過是用道具 來製造。 『v27855』希望有pk模式。答：已經有！ 『avatarofwarz』建議：加入熱鍵快速拿取道具欄的道具，亦可以隨時轉換道具位置。或建立拿取道具的優先制度：如空手重視，即一拿到道具 便會自動轉為空手。補給品重視，即是當拿到補給品時會自動放到道具欄的優先位置；而武器重視亦如此類推。答：很好的建議，已經跟小熊商議過， 但現階段會以製作遊戲工能為優先次序。 『choi9511』建議在街上增加NPC。例如阿婆，她一出現就會掉橙落地。你扶起她，就會補充滿血。若你不幫她就會減名聲和1分鐘內無法攻擊。 答：很有趣的建議，而在遊戲內已經出現了很多NPC。 『水果小堅哥』建議1.增加向上走、向下走動作，這樣看起來比較自然。2.增加超攻擊，在隨機情況下可擊出比平常兩倍威力的拳。3.增加能力值 道具，服用後指定能力提升。4.增加超必殺技，在條件達成後可使出超必殺技，使出後則重新執行條件。答：1.可以考慮。2.已經有以一敵十拳， 算不算超攻擊？3.能力道具應該會有。4.超必殺技亦會有。 『dickycth』建議為物品增設稀有度，數值越高，掉出來的機率便越低，可於任務中途取得。答：LFO內早晚會推出更多不同的道具，留意了！ |
