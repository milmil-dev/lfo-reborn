📅 2004-08-28

蕃薯集中營 三十五 各位蕃薯好！香噴噴、熱辣辣的蕃薯集中營又出爐了！這個星期製作組的同事都相當緊張，由於LFO公開版原本預計會在早幾天前面世，所以各人都非常 緊張。由於這次跟上次封測的情況可說是天淵之別，至少人數會急劇上升，我們都未曾真正面對過多人登入伺服器的情況，所以都有點擔心，最怕有一些 預計不到的事情發生，影響了遊戲的質數。特別是始祖和星爺，他們這幾天都沒有睡得好，星爺連日來趕忙建立多一台伺服器，做過封測的測試員都應該 知道原本只開放「山頂」伺服器，現在連「中銀」伺服器也開放了，預備成千上萬的新玩家登入。不過我們也預計不到會有多少人進入，不過根據多方面 的數據預測，極有可能會相當擠擁，所以如果公測頭一二個星期，伺服器方面可能會有點不隱定，希望各位見諒，及給予我們多點耐性去工作。 遊網誌原定在26日那天出版，可是雜誌發行那邊好像出現了點技術問題，所以推遲了。由於太多蕃薯都等得非常心急，早兩天老總都跟那邊的編輯談論過 ，至今天早上還未見有書賣，不過相信今天下午都會推出的。不過蕃薯們不用太過憂心，因為我們也跟另兩本遊戲雜誌，分別是「PC GAME 2000」和 「PC GAME WEEKLY」傾談過，他們下期也會隨書附加《Little Fighter Online Beta Version 1.0b》的光碟。至於兩本雜誌也會以LFO的人物作封面，所以 大家只要見到書本封面印有《小朋友齊打交Online》的角色，買了都應該會得到光碟的，放心吧。 這幾天隨了星爺和始祖趕起「中銀」伺服器外，小熊和莊青也努力地修改及增加遊戲內容。這次公開測試版更增加了裝備系統，會有很多不同的防具在打怪時 得到，其中我最愛是運動手錶和波鞋。不過可以預先告訴大家最利害的道具另不是在故事模式中打怪得到的，而是在對戰模式中，跟電腦對戰。不過電腦大多數 時間只會派出一般的角色跟你對戰，所以打敗他們都只會有機會得到一些較好的道具，最利害的道具則要視乎閣下的運氣了！如果你好運，可能在對戰模式中 碰上更利害的隱藏高手，更有萬份之一的機會在公測版中碰見「邪鬼」！！！嘩！只要打倒他，便有機會得到最利害的防具或武器！勁！！到時閣下要稱霸LF界 真是指日可待！這個加強了的對戰模式，是裝作組的另一趕制好的新系統，希望大家會喜歡。 還有一件事是要告訴所有舊有的測試員。雖然你現時已經安裝了的遊戲可以下載到更新檔，但當進入遊戲時，由於有部份程式已經原全不同，所以如果你還是用 舊有的光碟進行遊戲，必定會在中途「當機」。所以你們不要誤會只需要新的帳號和密碼便可以玩LFO，必定需要先移除舊版LFO，然後重新用新的 《Little Fighter Online Beta Version 1.0b》光碟安裝一次，避免你們的電腦發生問題。請注意！！！ 好，現在開始解答問題： 『moron』建議：1.道具合成 -
