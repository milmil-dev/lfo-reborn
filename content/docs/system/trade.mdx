| 經驗值說明 | | | | |
| SET 1： 在想與之交易的玩家身上按右手鍵選擇【物品交易】。 | | | | |
| SET 2： 當那位玩位同意交易後，就會進入交易模式。 這是雙方頭上會出現交易圖示，而畫面上也會出現一個交易視窗。 | | | | |
| SET 3： 將想交易的道具或金額拉向交易視窗中的交易欄內。 注：所有已放在交易欄上的道具也會變成紫色，已方便玩家知道自己正要交易的道具是什麼。 | | | | |
| SET 4： 當完成要交易的道具或金額的操作後，便可以按【確定】等候對方操作。 注：當按了【確定】後，玩家不能再增加或取走交易欄上的道具，如想做以上的動作，請先按一次【確定】鍵解除鎖定再操作。 注2：如玩家在對方按下【確定】後更改物品或調整金額，系統會立刻解除對方的【確定】狀態。 | | | | |
| SET 5： 當雙方按了【確定】後，系統會再出現訊息詢問玩家是否要進行是次交易。 注：當交易進行到這程序時，雙方均無均法再更變交易欄中的道具或金額數量。 | | | | |
| SET 6： 小心核對所交易的物品是否正確，如沒問題，便可以按【是】等候對方確認這次交易。 | | | | |
| SET 7： 當雙方都按【是】同意是次交易後，系統會出現交易完成的訊息。而交易亦就此完成。 | | | | |
