# 系統說明

系統說明 - LFO資料博物館 

### 

每一只兇獸都有一款獨特的魔精石，而每款魔精石都有不同的威力。兇獸獵人更可帶著「魔精石」及「魔劍」找尋藏身在維修店的神秘人，只要將兩種物件交給他，他可以幫你將魔精石鑲嵌在魔劍上，煉化成威力更強、性能更特別的武器。特別留意魔精石和魔劍都是無法交易的，所以特別的武器便顯得更為珍貴了。 

兇獸突襲系統還有其他神秘要素，現在只公報這些，其余的留待玩家們努力發掘吧！快跟朋友組成兇獸獵人小組，合力捕捉七只兇獸啦！
