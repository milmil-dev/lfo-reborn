LFO Wiki 是基於「**LFO資料博物館**」的資料所重建的開源 wiki，以現代化的方式保留 Little Fighter Online 這個曾陪伴許多玩家的遊戲。

## 原站致謝

- **原站站長：** 魔法使命者 (BOC@HK)
- **原站網址：** [lfostory.pages.dev](https://lfostory.pages.dev)
- **特別鳴謝：** Chik、Stanley、Andi、Break

原站由魔法使命者獨力收集、整理、維護多年，從官方網站備份了大量珍貴資料，包括 82 期蕃薯集中營開發日誌、角色資料、劇情連載、系統說明等。沒有這些資料，本站無法存在。

## 本站目標

- 以 Fumadocs 重建，讓內容在現代瀏覽器順暢呈現
- 開源，歡迎社群協作修正內容
- 保留所有原始資料的完整性

## 貢獻

每一頁右下角都有「在 GitHub 上編輯此頁」的連結，發現錯誤或有新資料歡迎提 PR。
