參加方法： 

SET 1：想參加比賽的玩家，請先自行組隊，然後請隊長click入 【立即報名】 進入 登記網頁 ，然後按指示填入所需資料，英文真實姓名 (請以身份証形式及大階填寫，如名字是賴家威，請填上LAI KA WAI) 、電郵地址、聯絡電話、帳號名字、參賽的角色名稱、所在伺服器及隊友的帳號名字等填寫好表格內，再按【登記】。 

SET 2：接著請隊友自行進入 登記網頁 ，然後按指示填入餘下的資料，再按【登記】，便完成參加的所有操作。 註1：每個帳號只能作一次登記，如帳號已被登記將不能取消，請玩家輸入資料時小心核對清楚，以確保輸入正確。 註2：為了方便隊長查閱隊友是否已將資料輸入，只要再次進入登記網頁便可以查閱隊友有否輸入資料。 

比賽規則： ‧二人為一隊，不設等級限制。 ‧ 比賽將會採用即時淘汰的方式進行比賽。 ‧ 參賽角色的資料將會被複製到比賽伺服器中。 (複製的資料包括角色等級、能力、招式、身上裝備及異轉系統。) ‧ 所複製的角色資料是以6月29日早上的記錄為準，如比賽時玩家發覺角色資料有異，均不得異議。 ‧ 隊伍內不能使用相同角色參賽。 ‧ 進行比賽前，參賽者需要重新裝著身上裝備。 ‧越一科技有限公司保留最終修改權力及比賽最終決定權，並可依實際情況予以增刪、修訂或變更比賽辦法，如有任何變動將會在「小鬥士大冒險Online」官方網站內公告，敬請隨時注意。 

比賽流程： ．首先是次預選賽會先將所有入選玩家按角色所在的伺機器分成6組，然後在進行即時淘汰賽。 ．每個伺服器的勝利隊伍會將會進入最後8強，參加在動漫節07內舉行的終極拳皇盃，角逐最強皇者的寶座，獲取更強獎品。 ．另外2個最後8強的名額會透過即時報名比賽產生，詳情留待日後公報。 預選賽 

如果錯過了報名或未被抽中的玩家請不用失望，你們還可以於比賽當日即場報名參加，想競逐最高殊榮，就記得在活動當天提早出門，霸定頭位唷！ 

即場報名比賽者，請注意以下細則： ．是次比賽採用隊伍抽籤制，工作人員會在活動當天的12點半開始為玩家進行登記，所以請玩家先自行組隊後再排隊登記。 
．為了避免出現混亂的情況，工作人員只會為頭50隊的排隊者進行登記。 
．當50個名額登記完成後，工作人員會立刻進行抽籤，選出16隊進入現場比賽。 
．即埸參加的人仕所以使用的角色為官方指定角色，對於使用的角色是誰均不得異議。 
．指定角色分別為迪雲、悟地、米兒、小丹四個角色。 
．指定角色能力為lv120、hp1500、mp1500、sp1500、攻400、防400、敏400(如角色能力有所改變，官方不會再作通知)
