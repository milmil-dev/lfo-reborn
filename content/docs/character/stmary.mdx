# 神母號-St.Mary

## 角色簡介

為了令自己心愛的素心復活，迪諾夫便將素心遺體改造成神母號，而由於同時得到「終極魔心臟」及「玄通器」這兩件擁有強大力量的物品，因此神母號除了擁有最先進的性能，還懂得使用「超級元力」，絕對是迪諾夫的最強皇牌！
