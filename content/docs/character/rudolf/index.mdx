# 陸道-Rudolf

## 角色簡介

迪雲等人在參加元武會考試時認識的其中一位參加者， 是甲賀派唯一的傳人，為了報殺父之仇，一路到處流浪修練，有一天聽聞學習元力可以令自己變得更強，便參加了元武會的考試。
