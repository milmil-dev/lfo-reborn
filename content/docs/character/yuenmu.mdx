# 玄武-Yuenmu

## 角色簡介

虎山派掌門龍武的師兄，為人勤奮好學，醉心研究各種武術，為了創出更強的武術而潛心修煉，終於創出以虎山拳法為基礎的醉虎拳和怒虎棍法。(前名:伏虎棍法)
