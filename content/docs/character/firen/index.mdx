# 菲雲-Firen

## 角色簡介

四大元素尊者之一，擁有操控火元素的力量，是冰尊者－菲沙的弟弟，為人火爆自大，雖然常常因為小小事而大發脾氣，但其實他是一個很會照顧別人的人
