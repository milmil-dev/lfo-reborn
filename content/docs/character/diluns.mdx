# 迪倫-Dilun

## 角色簡介

迪雲的哥哥，也是神秘組織『上帝之手』的組員，為人冷酷無情，對敵人從不留手，而且十分尊敬父親迪諾夫搏士，從不違背他的說話，為了完成父親的指令，就算犧牲自己性命，迪倫也在所不辭。
