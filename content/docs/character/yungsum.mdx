# 勇心-Yungsum

## 角色簡介

五大古龍騎士之一，天生擁有永久復活的特殊體質而被撒旦教主－撒卡看中，亦由於勇心擁有這特殊體質的關系，因此使用「燃燒生命的拳術」，既不怕耗盡生命力，威力也十分驚人。
