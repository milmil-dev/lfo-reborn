# 托比-Tobi

## 角色簡介

住在非洲南部小村落，常常背著回力標。別名小力的托比，是蘿拉的親弟弟，為人活潑開朗，遺傳姐姐蘿拉的性格，托比也十分喜愛幫助別人。年紀小小他，更是村中的小獵人，每天跟隨其他獵人一同打獵。
