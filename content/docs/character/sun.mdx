# 申武玄-Sun

## 角色簡介

星仔等人在中國參加元鬥士考試中認識的其中一位參加者，在考試途中被亡靈所依附及控制著，幸得星仔他們的幫忙才能脫險，此後申武玄深深明白自己實力不濟的事實，從而放棄考試，回到修練地方繼續修練。
