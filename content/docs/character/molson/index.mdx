# 巫神-Molson

## 角色簡介

魔人組織【亂】其中一名成員，性格高傲，對人類抱有極強的敵意，善長使用失傳已久的巫術直接攻擊對手的大腦神經，使其產生嚴重的幻覺，最後因精神崩潰而死。
