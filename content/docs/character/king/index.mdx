# 黃帝-King

## 角色簡介

相傳是遠古時代的三位超人類之一，也是遠古時代的霸主，因為接受了另一位實力旗鼓相當的超人類蚩尤挑戰而展開了世紀之戰，就在激戰過程中二人誤將魔界之門打開，最後為了阻止妖魔降臨，於是便和蚩尤、女媧聯手，合力將魔界之門封印。
