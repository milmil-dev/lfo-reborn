# 馬龍-Milo

## 角色簡介

寶瑪莉中學的搏擊社的隊長，也是「青狗社」的頭目，為人霸道，好勝心強，但十分重情重義，幫助兄弟時更會義不容辭。成為元鬥士後更加倍鍛煉元力，希望日後能為元武會作出貢獻。
