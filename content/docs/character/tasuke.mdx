# 陸島橋之助-Tasuke

## 角色簡介

陸道的父親，也是甲賀派的門主，為人開明、領導才能高、做事又認真，深得甲賀派所有人的歡迎，而為了守護「破邪劍」、「索命劍」兩把重要秘寶，每天都艱苦地進行各種修練。
