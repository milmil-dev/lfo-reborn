# 龐士-Omegah

## 角色簡介

邪惡組織「血骷髏軍團」首領，性格陰險奸詐，為了達到目的，犧牲同伴的性命也沒所謂，創立組織的最大目的，就是要打開人界和魔界的通道，從而使魔族統治人界。
