# 魔姥-Marek

## 角色簡介

神秘組織【亂】的十三魔人之一，善長利用蠱蟲操控別人的身體來攻擊敵人的蟲型魔人，由於自身沒有足夠的保護能力，所以魔姥會找尋合適的身體作寄宿之用。
