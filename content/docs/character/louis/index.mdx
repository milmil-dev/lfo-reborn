# 龍翼-Louis

## 角色簡介

虎山派龍武的親生兒子，也是悟地的師弟，由於天資聰敏，自小已練成一身好武功，但性格自私冷漠，就因為龍翼這種性格令龍武不肯將虎山派絕學「虎翔霸」傳授給他，龍翼一怒之下便離家出走。
