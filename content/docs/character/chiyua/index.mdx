# 蚩尤-Chiyua

## 角色簡介

相傳是遠古時代的三位超人類之一，為了確定自己的實力在眾人之上，於是便和另一位實力旗鼓相當的超人類黃帝展開世紀之戰，就在激戰過程中誤將魔界之門打開，為了阻止妖魔降臨，於是便和黃帝、女媧合力將魔界之門封印。
