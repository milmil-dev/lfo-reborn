# 邪狼丸-Jaro

## 角色簡介

伊賀五剎神之一，身形及樣貌就如其名一樣與狼極為相似，使用以精鋼制造的雙爪為武器，擅長化身為不同動物的形態作攻勢，見識過其力量的人遠見他的蹤影都被會他的氣勢攝過來，并喊出「狼來了」
