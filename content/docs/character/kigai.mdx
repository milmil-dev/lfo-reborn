# 鬼鎧-Kigai

## 角色簡介

伊賀五剎神中的首領，也是伊賀派的門主，由於手上持有由忍者王服部半藏遺留下來的四本『虎之卷』，因此實力超強，憑一人之力已可和當時的天尊者宇歷斯匹敵。
