# Freeze (菲沙)

## 角色簡介

四大元素尊者之一，擁有操控冰元素的力量，雖然外表冷酷，但其實內心充滿熱誠，加上戰鬥力高，是可以依靠的伙伴。

## 角色專用武器

| 項目 | 內容 |
|------|------|
| 名稱 | 冰封之劍 |
| 成份 | 布料 |
| 特效 | 劍氣+凍結 |
| 耐久 | 20 |
| 說明 | 由菲沙的招式所製造出來的冰凍之刃 |
