# 索特-Sola

## 角色簡介

居住在魔界中的魔人，是魔界最強戰士「終極魔人」的最好朋友，一直都向往著人類世界，因此在黃帝、蚩尤展開世紀之戰，誤將魔界之門打開的時候，偷偷尾隨十三魔人前往地球
