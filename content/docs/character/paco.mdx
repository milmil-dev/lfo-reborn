# 柏高-Paco

## 角色簡介

是美國其中一個特種部隊「飛鷹特工隊」二隊Ｂ組隊長，專門負責調查在世界各地的神秘組織。 為了調查突然掘起的神秘組織「上帝之手」，於是便跟隨迪雲等人一起行動。
