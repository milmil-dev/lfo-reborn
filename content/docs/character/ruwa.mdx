# 女媧-Ruwa

女媧-Ruwa - LFO資料博物館 

### 

~角色簡介~ 相傳是遠古時代的三位超人類之一，亦是第一代大魔導士。雖身為女兒之身，但其實力絕不低於當時的黃帝及蚩尤。 在誤開『魔界之門』的事件中，與黃帝、蚩尤聯手將最強魔人『終極魔人』擊退，并合力將魔界之門封印。
