# 桐生雪姬-Yuki

## 角色簡介

伊賀五剎神之一，善長使用水遁忍術及心理戰術的她，為人十分冷酷，分析能力又高，對敵人更絕不留情；而且在多次任務中也有杰出表現，因此外間一直稱她為伊賀「雪女」。
